# Formulário de Matrícula
Este projeto é uma landing page de formulário de matrícula para uma escola infantil, criada com HTML e CSS.

# O que contém
- Estrutura de formulário com campos para dados da criança, endereço, responsável e opções de matrícula;
- Estilização customizada com layout dividido em duas colunas;
- Elementos como inputs, selects, textarea, radio buttons, checkbox e área de upload de arquivo;
- foco em prática de marcação semântica e organização de estilos.

# Como visualizar
1. Abra o arquivo index.html em seu navegador.
2. Ou sirva a pasta com um servidor local simples, como o Live Server.
